Single Cloudflare Worker entry at `src/index.ts` bootstraps a typed Hono app (`Hono<{ Bindings: Env }>`) that mounts five route modules under `/api/{translate,vocab,review,sessions,tracks}` plus `/api/plan` and `/api/health`, and serves a SPA from `public/`. The `ai/` layer abstracts any OpenAI-compatible chat-completions endpoint (DeepSeek, OpenAI, or generic `openai-compatible`) behind an `AIProvider` interface configured entirely from `wrangler.toml` vars/secrets; routes consume it via `getProvider(env)`. Business logic is split into `services/`: `srs.ts` implements FSRS scheduling with context-linked review cards, streaks, and retention stats (scheduling primitives live in `fsrs.ts` via ts-fsrs); `teach.ts` handles free-form teaching flows; `tracks.ts` seeds the HSK1 curriculum and generates AI track lessons; `plan.ts` computes the adaptive daily plan; `rate-limit.ts` enforces per-IP limits. Persistence is exclusively through Cloudflare D1 SQLite, with schema in `migrations/` (0001: vocab/sessions/review_log/rate_limits; 0002_sessions_dedup + 0002_memory_and_tracks + 0003: fsrs_state, sessions.kind, input_norm dedup key, tracks/track_items/track_progress). Shared types live in `src/types.ts` (Env bindings) and `src/db.ts` (row shapes). Static assets are synced from the sibling web app via `scripts/sync-web.sh` before deployment.
