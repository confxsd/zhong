Single Cloudflare Worker entry at `src/index.ts` bootstraps a typed Hono app (`Hono<{ Bindings: Env }>`) that mounts four route modules under `/api/{translate,vocab,review,sessions}` and serves a SPA from `public/` with `/api/*` requests routed to the worker first. The `ai/` layer abstracts any OpenAI-compatible chat-completions endpoint (DeepSeek, OpenAI, or generic `openai-compatible`) behind an `AIProvider` interface configured entirely from `wrangler.toml` vars/secrets; routes consume it via `getProvider(env)`. Business logic is split into `services/`: `srs.ts` implements a Leitner-style spaced-repetition algorithm (box-based intervals in days), `teach.ts` handles teaching flows, and `rate-limit.ts` enforces per-IP limits using the `rate_limits` table. Persistence is exclusively through Cloudflare D1 SQLite, accessed via `c.env.DB.prepare(...).bind(...)` parameterized queries, with schema defined in `migrations/0001_init.sql` (vocab, sessions, session_vocab, review_log, rate_limits tables plus indexes). Shared types live in `src/types.ts` (Env bindings) and `src/db.ts` (row shapes). Static assets are synced from a sibling web repo via `scripts/sync-web.sh` before deployment.
